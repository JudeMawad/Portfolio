# Il Siciliano

Standalone restaurant concept at <https://judemawad.com/il-siciliano/>. This directory is a generated Next.js static export, independent of the portfolio homepage and navigation.

To update it, build the restaurant source with `NEXT_PUBLIC_BASE_PATH=/il-siciliano` and `NEXT_PUBLIC_SITE_URL=https://judemawad.com/il-siciliano`, then replace this directory's generated files with the contents of `out/`. Preserve this note and `LICENSE`.

Keep the repository-root `.nojekyll`: GitHub Pages must serve the `_next/` assets. Restaurant routes retain `noindex` metadata. Menu content is a dated local snapshot, not a live ordering service.

Original application: [BinaryLeo/next_js_pizza_ordering](https://github.com/BinaryLeo/next_js_pizza_ordering), MIT licensed. Food and venue imagery remain subject to their respective owners' rights.
