Along the way

A few things I’ve learned from studying, building projects, and figuring things out along the way.

  1. 01 01

    Starting out

    Learning by Building

    University gave me the fundamentals, but a lot of things only started to really make sense once I had my own projects and a reason to use what I was learning.

  2. 02 02

    Finishing things

    Shipping Is Different

    Building IGNITE taught me that getting the main idea to work is only part of the job. The rest is fixing edge cases, changing things that seemed finished, and eventually deciding when to stop.

  3. 03 03

    Working with others

    Other People’s Code

    Team and professional projects showed me how different it is to work in code you didn’t write yourself. Understanding existing decisions and working around other people’s work is a skill of its own.

  4. 04 04

    Keeping things running

    Working Once Isn’t Enough

    Running my own server made me deal with the less exciting parts too: updates, networking, permissions, failures, remote access, and keeping services working after the initial setup was done.

  5. 05 05

    Learning new tools

    Figure It Out as I Go

    A lot of the tools I use now started with a project that needed something I didn’t know yet. That’s how I ended up learning more about Linux, networking, Blender, Fusion 360, electronics, and 3D printing.

  6. 06 06

    Right now

    Hardware Is Different

    Building THE CUBE has been a different kind of iteration. A wrong dimension means another print, a wiring change means opening things back up, and sometimes the easiest software fix doesn’t exist in hardware.
